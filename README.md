# Portfolio: Digital Marketing & AIGC

Single-page portfolio site. Everything lives in `index.html` (no build step).

## Editing content

Text highlighted in yellow on the page is placeholder content. In `index.html`,
search for `class="ph"` and replace each placeholder with your own text, then
delete the `ph` class (or the wrapping `<span class="ph">`) so the highlight disappears.

Also replace `https://www.linkedin.com/in/YOUR-LINKEDIN/` (two places).

## Hosting

Served by GitHub Pages from the `main` branch root.
